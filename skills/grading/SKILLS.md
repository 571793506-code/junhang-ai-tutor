# 批改类 Skill

用于修改、复用或审查图片批改、答案键对齐、OCR 识别、逐题复核、低置信拦截和教师确认归档经验。当前阶段只沉淀流程经验，不把现有复杂自动批改链路继续扩大为默认实现。

## 适用场景

- 学生或老师上传作业、小测、试卷、听写图片，需要识别作答并形成批改草稿。
- 需要区分已有生成材料批改和外部材料批改。
- 需要判断低置信结果是否允许出最终分或写入学生档案。
- 需要生成图片上传后的老师侧待复核摘要。

## 核心原则

- OCR、学生作答识别、标准答案和归档必须分层处理。
- 有答案键、生成记录或 `questionLayoutManifest` 时优先使用它们，不重新猜题。
- 没有答案键时先生成参考答案，再标记置信度和复核风险。
- MiniMax 视觉 OCR 多页识别最多 2 路并发，结果必须保持页序稳定；在 GPT-5.6 图片能力通过实测前，不迁移视觉识别。
- 单一明确答案的选择、短填空和数值题优先在服务层保守比较；多解、开放题、过程题、阅读简答、英语表达和作文必须交给 GPT-5.6。
- 混合题只把未解决题目、对应作答和参考答案发送给 GPT-5.6；总分必须由逐题得分汇总，模型顶层分数不得覆盖。
- 低置信、漏页、题目缺失、学生作答缺失、图片质量差、参考答案不可靠或模型分歧时，不出最终分、不入档、不发布。
- 教师确认后才写入学生档案、错题记录和薄弱点分析。
- 默认主链路执行 OCR/视觉识别、答案键优先、客观题本地比较、GPT-5.6 主观题批改、低置信标记和教师逐题复核。`uncertain`、低置信或总分不一致时只触发一次 GPT-5.6 风险审查，不继续串行调用多个模型。
- `gpt-5.6-terra` 的外部材料参考答案生成、主批改和高风险复判统一使用 `high`；提高推理档位不改变低置信拦截、教师逐题复核和确认后归档边界。
- 只有可恢复的 availability 故障，以及答案/解析缺失、批改结论冲突、证据充分但低置信等明确 quality 故障，才允许把最小失败题升级到 `gpt-5.6-sol` 的 `high`。配置、鉴权、模型不支持等 configuration 故障不能升级；OCR、题干、学生作答或参考证据不足属于 evidence 故障，直接进入教师复核。
- 每个失败题最多一次 Sol，局部参考答案或批改独立预算为 180 秒 / 12000 tokens；Sol 后不得串接 DeepSeek 或第三个文本模型。Sol 仍失败、结果冲突或质量门禁不通过时，只保留待复核结果。
- `usedModelEscalation`、模型名、档位、触发原因和预算只属于内部运行元数据，不得展示给学生、家长、课堂平板或公共屏。Sol availability 和合成质量样本只证明链路可用，不能证明生产批改正确率；正确率必须使用教师确认的 gold 数据评估。

## 两条处理路径

已生成材料：

- 使用 `assignmentId`、题目、答案、分值、解析和 `questionLayoutManifest`。
- 只识别学生作答区域，按题号对齐。
- 这是最高准确率路径。

外部材料：

- 先识别印刷题干、学生作答、页序、清晰度和题目区域。
- 再生成参考答案和评分点。
- 最终只给教师待复核草稿，不自动归档。

## 推荐输出形态

教师端批改输入应整理为明确动作：

```text
批改上传图片
使用答案：1.A 2.C 3.略
```

输出建议包含：

- 图片质量和页数判断；
- 已识别题号和学生作答摘要；
- 有答案键时的逐题辅助判断；
- 无答案键时的参考答案草稿；
- 低置信项；
- 需要老师确认的分数和题目。

## 禁止项

- 不自动把批改结果发布给学生或家长。
- 不自动归档低置信结果。
- 不把当前多模型批改审查链作为默认主链路继续扩大。
- 不把印刷题干、示例答案或 OCR 混合文本当作学生作答。
- 不在普通端展示模型、供应商或内部评分链路。

## 验证

- 修改批改 API 或工作台服务时运行 `cmd /c npm.cmd run check --workspace apps/api`。
- 修改 Web 批改原型时运行 `cmd /c npm.cmd run typecheck --workspace apps/web`。
- 涉及小程序既有快照时运行 `cmd /c npm.cmd run check:miniprogram-js`，但当前阶段不新增小程序功能。
- 修改中文提示词、批改文案或归档规则时运行 `cmd /c npm.cmd run check:encoding`。
- 有教师确认金标样本时，运行 `cmd /c npm.cmd run check:grading:quality -- <gold-cases.json>`；没有金标结果前不得宣称批改正确率已达生产标准。
