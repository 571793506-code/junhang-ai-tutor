## 使用边界

- 当前项目只使用综合成长档案模板，不使用单科独立模板。
- 周/月候选图只供教师端 UI 和打印模板信息层级讨论。
- 正式周/月打印版和 PDF 正文必须来自 `printView` 结构化数据和 HTML/PDF 模板渲染。
- image 2 生成图中的中文、图标和占位内容不得直接作为家长可见正式正文。
- 家长可见内容不得包含排名、预测分、冲刺、升学风险、班级位置、模型、供应商、接口或调试字段。
