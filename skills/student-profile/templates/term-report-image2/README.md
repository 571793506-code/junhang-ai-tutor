## 使用边界

- 候选图可用于教师端 UI 视觉讨论和 PDF 模板方向选择。
- 正式 PDF 必须由项目 HTML/PDF 渲染链路生成文字，不能直接把 image 2 图片作为报告正文。
- 161700 版本只代表当前推荐信息结构，不代表图片中文字可直接定稿。
- 家长可见内容不得包含排名、预测分、冲刺、升学风险、班级位置、模型、供应商、接口或调试字段。
- 如要进入定稿，需人工复查所有中文、错别字、缺字方框和内容边界。
