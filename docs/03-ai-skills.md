# AI Skills 草案

AI 大脑拆成多个稳定 skill，每个 skill 都有输入、输出、约束和可记录字段。

## 第一阶段 skills

### 背书听写评估

- 输入：学生、年级、课文/词表、学生作答或语音识别文本。
- 输出：错字、漏词、顺序错误、熟练度、复习建议。
- 记录：听写项、错误类型、掌握度变化。

### 小升初英语词汇助手

- 输入：单词/短语/句子、年级、教材版本。
- 输出：中文意思、词性、搭配、例句、易错点、考法、造句反馈。
- 约束：解释符合小学高年级理解水平。

### 知识问答

- 输入：学生问题、上下文、年级、学科。
- 输出：短答案、分步解释、例子、再练一道。
- 约束：未知或高风险内容要说明不确定，必要时建议问老师。

### 作业试卷生成

- 输入：年级、学科、知识点、题型、难度、题量。
- 输出：题目、答案、解析、评分标准。
- 约束：避免超纲，标明知识点和难度。

### 作业批改

- 输入：题目、标准答案、学生答案、图片识别文本。
- 输出：对错、得分、错因、讲解、同类题建议。
- 约束：低置信度时提示老师复核。

### 错题归因

- 输入：错题、学生答案、历史表现。
- 输出：错因分类、知识点、复习建议、重练题型。

### 学生档案生成

- 输入：行为日志、任务结果、错题、老师备注。
- 输出：日/周/月/期中/期末报告。
- 约束：事实驱动，不夸大，不做医学或心理诊断。

## 第二阶段 skills

- PPT 课件生成。
- 语文作文批改。
- 数学空间图形讲解。
- 虚拟课堂场景生成。
- 家长沟通话术生成。
- 老师备课助手。
