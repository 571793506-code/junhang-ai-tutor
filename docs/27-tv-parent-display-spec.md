# 电视投屏端家长参观动态屏设计

## 1. 页面定位

电视投屏端是给家长、来访者和校区现场看的“整体学习观察屏”。

它不是操作端，不做学生交互，也不展示单个学生隐私。它的核心任务是：

- 让家长直观看到系统正在持续记录学习过程。
- 让家长理解 AI 助教并不是噱头，而是在做识别、分析、归档和反馈。
- 让来访家长感觉机构有专业流程、有老师把关、有长期数据沉淀。
- 和平板端形成联动：平板负责互动，电视负责展示整体动态。

一句话定位：

> 电视端负责让家长看懂“孩子们今天学了什么、AI 做了什么、老师跟进了什么”。

## 2. 展示原则

### 2.1 只展示整体

电视端可以展示：

- 年级/班级整体任务数量
- 今日完成概览
- AI 已生成反馈数量
- 老师已查看/复核数量
- 共性知识点观察
- 常见错因
- 匿名课堂投票结果
- 听写、跟读、问答等插件动态

电视端不展示：

- 个人分数
- 学生排名
- 单个学生完成度
- 单个学生错题详情
- 单个学生问答全文
- 家长手机号
- 教师内部复核意见

### 2.2 强调过程，不强调输赢

电视端不做“谁更好”的表达，而做“系统如何帮助学习”的表达。

推荐表达：

- 学习过程可追踪
- 错题持续归档
- AI 先分析，老师再复核
- 阶段反馈可阅读
- 待巩固方向更清楚

避免表达：

- 第一名
- 领先
- 落后
- 超过多少同学
- 完成度最高
- 错题最多

## 3. 页面信息架构

建议电视端采用 16:9 大屏布局，模块稳定、局部动态。

### 3.1 顶部状态栏

内容：

- 产品名：君航 AI 助教
- 页面名：家长参观动态屏
- 年级/班级
- 日期和时间
- 当前模式：家长参观模式
- AI 状态：识别中 / 分析中 / 老师复核中 / 反馈归档中

示例：

> 君航 AI 助教 · 家长参观动态屏  
> 三年级 · 今日学习观察 · 家长参观模式

### 3.2 中央主视觉：AI 助教实时工作流

中央区域是电视端最重要的科技感来源。

建议展示一条动态流程：

> 教师发布 -> 学生学习/提交 -> AI 识别分析 -> 老师复核 -> 学生端反馈 -> 阶段归档

每个节点有状态：

| 节点 | 状态示例 |
| --- | --- |
| 教师发布 | 今日任务已发布 |
| 学生学习/提交 | 学习记录持续写入 |
| AI 识别分析 | 作业图片识别中 |
| 老师复核 | 反馈等待确认 |
| 学生端反馈 | 已同步今日建议 |
| 阶段归档 | 写入成长档案 |

动效建议：

- 节点轻微呼吸
- 数据线缓慢流动
- 当前节点有高亮
- 完成节点显示柔和对勾
- 等待节点显示微弱光点

### 3.3 左侧：今日任务完成概览

展示整体任务情况。

字段建议：

- 今日任务总数
- 已完成任务
- 待跟进任务
- AI 已生成反馈
- 老师已查看

展示方式：

- 环形图
- 数字卡片
- 趋势小折线
- 状态标签

注意：

这里展示整体数量，不展示具体学生和个人进度条。

### 3.4 右侧：共性学习观察

展示年级/班级整体需要关注的方向。

模块：

- 本周学习重点
- 常见错因
- 待巩固知识点
- 推荐复练方向

示例：

> 本周重点：乘除法应用题、英语 Unit 4 词汇、语文阅读概括  
> 常见错因：审题漏条件、词形变化不稳定、答案缺少依据句  
> 推荐复练：同类题复盘、错题订正后再练一道、重点词造句

注意：

共性观察要表达“帮助老师发现整体问题”，不要让家长联想到某个孩子被公开点名。

### 3.5 底部左侧：学生头像墙

头像墙可以出现，但只表达“这些学生都在系统里被记录和服务”。

展示规则：

- 只显示头像和名字/昵称。
- 不显示分数、排名、状态颜色。
- 不显示谁完成、谁未完成。
- 可缓慢轮播，增加现场活跃感。

如果家长隐私敏感，教师端可切换为：

- 昵称模式
- 仅头像模式
- 隐藏头像墙

### 3.6 底部中间：互动插件动态

展示近期或当前正在发生的互动。

插件动态示例：

| 插件 | 电视端展示 |
| --- | --- |
| 课堂投票 | 匿名结果：A 36% / B 48% / C 16% |
| 听写播报 | 听写播报进行中，第 3 题 |
| 课文跟读 | 今日重点词：bright / carried / yesterday |
| AI 问答 | 今日已归档若干条课堂问答 |
| 今日鼓励 | 今日鼓励已发送到学生端 |
| 小组协作 | 本周小队挑战预告：错题清零行动 |

不展示：

- 谁选了哪个选项
- 谁答错了
- 谁没有参与

### 3.7 底部右侧：家长可见成果

用稳定卡片解释系统价值。

建议 5 个卡片：

1. 学习过程可追踪
2. 错题持续归档
3. AI 初步分析
4. 老师复核把关
5. 阶段报告可阅读

这些卡片适合长期显示，帮助家长理解系统的“信任链条”。

## 4. 动态内容策略

电视端不需要一直变化，但需要有“系统正在工作”的感觉。

### 4.1 常驻动态

- AI 工作流节点流动
- 今日任务数字轻微刷新
- 状态点闪烁
- 头像墙缓慢轮播
- 插件动态卡片轮播

### 4.2 事件触发动态

当平板端或学生端发生事件时，电视端可短暂显示提示。

示例：

- 老师发布了今日任务
- AI 已生成一批学习反馈
- 批改记录等待老师复核
- 课堂投票已开启
- 听写播报正在进行
- 阶段报告已更新

提示文案必须匿名化。

推荐：

> 一条课堂问答已进入学习记录

不推荐：

> 李子越刚刚提问了一个数学问题

### 4.3 轮播节奏

建议：

- 主工作流常驻。
- 左右数据区每 20-30 秒轻微刷新。
- 互动插件动态每 8-12 秒切换一张。
- 头像墙每 15-20 秒缓慢滚动一批。
- 事件提示停留 3-5 秒。

## 5. 家长参观场景脚本

老师或前台可以用这套屏幕向家长说明：

1. 今天孩子们的学习任务会由老师发布。
2. 学生完成任务或提交作业后，系统会先进行识别和初步分析。
3. AI 生成的反馈不会直接作为最终结论，老师会复核后再发布。
4. 错题和学习记录会沉淀到学生端，家长可以查看阶段反馈。
5. 平板端提供课堂互动，电视端只展示整体学习动态，不公开比较孩子。

这套解释能同时体现：

- 专业
- 可控
- 有 AI 能力
- 尊重学生
- 家长可理解

## 6. 与平板端联动

### 6.1 平板互动 -> 电视展示

平板发生互动时，电视只显示整体状态。

示例：

| 平板动作 | 电视展示 |
| --- | --- |
| 学生拖头像进入 AI 问答 | 一名同学正在参与 AI 问答 |
| 学生完成课文跟读 | 一条课文跟读记录已归档 |
| 老师开启听写播报 | 听写播报正在进行 |
| 老师开启课堂投票 | 匿名课堂投票已开启 |
| 学生领取今日鼓励 | 今日鼓励已发送到学生端 |

### 6.2 教师端控制

教师端需要可控制：

- 是否开启电视投屏
- 投屏显示哪个年级/班级
- 是否显示头像墙
- 是否显示任务完成概览
- 是否显示共性学习观察
- 是否显示插件动态
- 是否隐藏全部人数
- 是否进入纯品牌展示模式

## 7. 视觉风格

关键词：

- 明亮
- 稳定
- 有科技感
- 不压迫
- 家长可读
- 大屏可视

建议：

- 背景用浅色科技网格。
- 主色为蓝、青、绿色。
- 少量橙色用于提醒，但不要用于风险标记。
- 字号足够大，远距离可读。
- 动效柔和，不要像监控大屏。
- 图表不要过密，避免家长看不懂。

## 8. 第一版模块优先级

第一版必须有：

1. 顶部状态栏
2. AI 助教工作流
3. 今日任务完成概览
4. 共性学习观察
5. 学生头像墙
6. 互动插件动态
7. 家长可见成果

第二版增强：

1. 实时数据刷新
2. 平板互动事件同步
3. 匿名课堂投票结果
4. 听写/跟读状态同步
5. 阶段报告更新提醒
6. 教师端投屏配置

## 9. 验收标准

电视端设计完成后应满足：

- 家长 10 秒内能看懂这是一套 AI 学习过程系统。
- 家长能理解 AI 和老师各自承担什么角色。
- 屏幕整体有科技感，但不是压迫式监控。
- 不出现排名、个人分数和个人差异放大。
- 平板端互动能以匿名整体方式反馈到电视端。
- 教师端能随时控制展示范围。
