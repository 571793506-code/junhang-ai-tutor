# 旧资料审计摘要

审计对象：`D:\君航AI助教`。该目录只作为新系统参考，不直接复用旧实现。

## 已确认内容

- `data/`：包含学生索引、会话记录、表现档案状态、教材索引和主题上下文。
- `students/`：包含学生档案、批改记录、日/月/期中期末档案、作业图片等。
- `textbooks/`：包含小学语文、数学、英语教材 `.edupdf`，旧索引统计约 32 本。
- `logs/`：包含旧飞书长连接、批改、报告生成、DeepSeek 出题、MiniMax TTS 等运行记录。

## 旧系统能力线索

- 飞书：
  - 使用过长连接事件客户端。
  - 生成过飞书云文档。
  - 发送过群消息、文件和批改摘要。
- DeepSeek：
  - 用于结构化出题和草稿生成。
  - 日志里出现过草稿可用性判断。
- MiniMax：
  - 用于词汇 TTS，日志里出现过失败降级记录。
- PDF/试卷：
  - 旧系统有 A4 PDF 试卷生成链路。
  - 曾区分学生卷和答案解析。
- 学生档案：
  - 已有日档案、月档案、期中/期末档案样例。

## 当前机器可用命令

- 可用：`node`、`npm`、`npx`、`git`。
- 未发现：`gh`、`lark-cli`、`deepseek`、`minimax`。
- 飞书桌面客户端正在运行，但未发现明确属于旧机器人的 Node 进程。
- Codex 自身的 `node_repl` 正在运行，不能停止。

## 风险与注意事项

- 旧教材索引和说明文件存在编码损坏迹象，需要重建教材索引。
- 旧数据包含学生真实记录，迁移前必须先做字段清洗和隐私边界确认。
- 旧日志中有大量飞书云文档 URL，可作为历史档案引用，但不应默认同步到新系统。
- 尚未发现可直接复用的 `.env`，新接入应重新提供或重新生成 API Key。

## 可复用为参考的东西

- 学生成长档案的表达风格。
- 批改记录的数据字段。
- 教材覆盖范围。
- PDF 试卷的功能需求。
- 飞书推送和云文档的业务流程。

## 不建议复用的东西

- 旧飞书长连接机器人主流程。
- 旧路径下的临时脚本。
- 旧日志中的错误重试策略。
- 编码损坏的教材索引。
- 无清洗的学生原始数据结构。
