# 数据库决策

## 选择

第一版使用 PostgreSQL + Prisma。

原因：

- 学生、任务、错题、行为日志、报告等数据结构清晰，适合关系型数据库。
- PostgreSQL 对 JSON 字段支持成熟，能承载 AI 输出的结构化结果和扩展 metadata。
- Prisma 适合 TypeScript 项目，便于快速迭代 schema、迁移和类型生成。
- 后续如果加入向量检索，可以使用 PostgreSQL 的 pgvector，先不引入额外数据库复杂度。

## 第一阶段数据边界

第一阶段不追求一次性覆盖所有未来功能，只保证学习闭环可落库：

- 学生与家长/老师绑定。
- 学科与知识点。
- 学习任务与完成记录。
- 背书听写。
- AI 问答。
- 词汇学习。
- 作业、题目、提交与批改。
- 错题本。
- 行为日志。
- 学生画像和阶段报告。
- AI 调用记录。
- 生成物索引。

## 后续扩展

- 教材索引先使用 `textbook_assets` 和 `knowledge_points`。
- 电子教材正文、音频和图片先作为外部素材索引，不直接塞入主表。
- 大文件进入对象存储，本库只保存 URL、hash、来源和权限信息。
- 3D 教学实验室生成物进入 `generated_assets`，与学生端数据分离。
