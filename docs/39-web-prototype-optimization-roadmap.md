# Web 原型优化路线

## 1. 当前策略

小程序暂缓迁移期间，继续在 Web 端做设计验证。

目标不是继续堆功能，而是把三块核心展示打磨到可以作为小程序迁移和现场演示的标准：

1. 电视动态屏。
2. 平板公共端。
3. 学生端模块化首页。

## 2. 优化优先级

| 优先级 | 方向 | 原因 |
| --- | --- | --- |
| P0 | 电视动态屏大屏观感 | 直接影响家长信任感 |
| P0 | 平板端拖拽解锁体验 | 直接影响学生参与感 |
| P1 | 学生端模块首页精修 | 影响家用入口体验 |
| P1 | 教师端控制入口设计 | 影响后续管理闭环 |
| P2 | 互动扩展概念展示 | 后续版本参考 |

## 3. 电视动态屏优化任务

### 3.1 排版优化

可优化项：

- 16:9 宽屏下减少顶部空白。
- AI 学习中枢和流程节点保持足够距离。
- 学科知识热力区域继续拉长，充分利用横向空间。
- 右侧队列和实时动态保持信息密度。

验收：

- 电视屏看起来不空。
- 每个模块都有明确数据含义。
- 站在 2 到 3 米外仍能看懂主信息。

### 3.2 动态数据优化

可优化项：

- 数字轻微滚动。
- 队列状态轮换。
- 匿名事件轮播。
- 热力块呼吸。
- 多年级条形图轻微变化。

验收：

- 页面有“系统正在工作”的感觉。
- 动效不刺眼。
- 不像广告屏，也不像冷冰冰后台。

### 3.3 文案优化

可优化项：

- 把“AI 学习中枢”下面的流程文案变得更贴近家长理解。
- 把“学科知识互动热力”解释得更清楚。
- 匿名事件避免过于技术化。

推荐文案方向：

- “AI 先分析，老师再复核。”
- “学习过程可追踪。”
- “阶段反馈可沉淀。”
- “这里只展示整体趋势。”

## 4. 平板公共端优化任务

### 4.1 头像轨道优化

可优化项：

- 头像数量多时每侧滚动。
- 当前拖拽头像放大。
- 拖拽时原位置留淡占位。
- 四周头像亮度降低，中心吸附时高亮。

验收：

- 学生能马上看懂“拖自己的头像到中间”。
- 不会误以为这是成绩墙。
- 多年级/多学生时不拥挤。

### 4.2 学习光环优化

可优化项：

- 拖拽靠近时光环放大。
- 进入吸附区时出现波纹。
- 松手后头像自然吸附到中心。
- 未进入中心时头像回到轨道。

验收：

- 交互有仪式感。
- 不像游戏排名。
- 家长看到会觉得有科技感和秩序感。

### 4.3 插件选择优化

可优化项：

- 解锁前插件低亮。
- 解锁后可用插件高亮。
- 入口型插件显示“老师开启后可用”。
- 插件文案更短、更像平板按钮。

验收：

- 学生知道下一步能点什么。
- 老师知道哪些是当前可用，哪些是后续扩展。

## 5. 学生端首页优化任务

### 5.1 模块卡片优化

可优化项：

- 今日任务卡片放第一位。
- AI 问答和英语词汇并列为学习辅助。
- 拍照提交更突出“提交后老师查看”。
- 学生档案突出“老师复核后反馈”。
- 互动扩展保持低调。

验收：

- 学生进入首页后知道先做什么。
- 家长能看懂孩子今天有哪些内容。
- 不出现过多未来功能。

### 5.2 状态摘要优化

可优化项：

- 今日任务显示数量。
- 拍照提交显示最近提交状态。
- 档案显示已发布反馈数量。
- AI 问答显示服务可用状态。

验收：

- 首页不空。
- 状态不焦虑。
- 入口和真实功能一致。

## 6. 教师端控制入口优化任务

### 6.1 电视动态屏入口

建议入口：

- 教师工作台增加“打开电视动态屏”。
- 可显示大屏地址。
- 可显示当前是否匿名展示。

当前 Web 原型已完成：

- 工作台中出现电视动态屏卡片。
- 显示“打开预览”和“复制大屏地址”入口。
- 明确电视动态屏用于家长参观数据屏。

### 6.2 平板展示模式

建议入口：

- 常规待机。
- 家长参观。
- 课堂互动。
- 听写锁屏。

第一版只做视觉配置，不需要复杂后端。

当前 Web 原型已完成：

- 工作台中出现平板展示模式卡片。
- 展示常规待机、家长参观、课堂互动、听写锁屏四种模式。
- 说明共享平板只确认本次互动身份。

### 6.3 插件开关

建议入口：

- AI 问答。
- 听写播报。
- 课文跟读。
- 课堂投票。
- 今日鼓励。
- 小组协作。

第一版可以只显示状态，不真正控制。

当前 Web 原型已完成：

- 工作台中出现互动插件开关卡片。
- 已有三项显示“可用”。
- 扩展三项显示“老师开启后”。
- 迁移前配置卡片明确先不进入小程序迁移。

## 7. 建议下一个 Web 端小迭代

### 迭代 A：电视动态屏精修

内容：

1. 加强顶部状态栏。
2. 优化 AI 中枢与流程节点距离。
3. 强化学科知识热力解释。
4. 增加匿名事件密度。

适合下一步优先做。

### 迭代 B：平板公共端精修

内容：

1. 优化四周头像轨道。
2. 增加拖拽提示。
3. 插件卡片状态区分。
4. 增加超时回到待机文案。

适合电视动态屏稳定后做。

### 迭代 C：学生端首页精修

内容：

1. 模块卡片文案收短。
2. 拍照提交和英语词汇入口更贴近现有功能。
3. 增加最近学习动态摘要。

适合平板端稳定后做。

## 8. 暂停线

在小程序迁移窗口开启前，不做：

- 小程序页面改造。
- 新增小程序路由。
- 小程序拖拽事件。
- 小程序样式迁移。

只做：

- Web 原型优化。
- 方案文档。
- 迁移预案。
- 数据规则设计。
