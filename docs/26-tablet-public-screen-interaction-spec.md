# 平板端公共互动屏详细设计

## 1. 页面定位

平板端是年级共用设备，不承担完整个人学习端职责。它的主要任务是：

- 给家长展示学习过程和 AI 助教能力。
- 给学生提供短时、轻量、有仪式感的互动入口。
- 给老师提供课堂中可控的互动工具。
- 给电视投屏端提供可同步的展示内容来源。

平板端不能成为公开比较学生表现的地方。

不展示：

- 学生排名
- 个人分数
- 单个学生任务完成度
- 单个学生错题详情
- 个人能力雷达
- 家长敏感信息
- 长期学习档案全文

可以展示：

- 年级整体任务概览
- AI 助教工作流
- 共性学习观察
- 学生头像墙
- 今日课堂内容
- 可用互动插件
- 匿名投票结果
- 听写、跟读、问答等互动状态

## 2. 平板首页结构

### 2.1 顶部区域

顶部用于表达当前设备身份和展示模式。

内容：

- 产品名：君航 AI 助教
- 设备名：三年级公共平板
- 日期和时间
- 当前模式：家长参观模式 / 常规待机 / 课堂互动 / 听写锁屏
- 网络/投屏状态

建议文案：

> 君航 AI 助教 · 三年级公共平板  
> 家长参观模式 · 可互动

### 2.2 中心区域

中心区域根据状态变化：

| 状态 | 中心内容 |
| --- | --- |
| 待机展示 | 今日学习概览 + AI 工作流 |
| 准备互动 | 学习光环 |
| 拖拽中 | 学习光环放大 + 磁吸轨迹 |
| 身份确认 | 当前学生头像 + 确认文案 |
| 插件选择 | 当前学生 + 可用互动插件 |
| 插件执行 | 当前插件主界面 |

### 2.3 四周头像轨道

学生头像沿四周分布：

- 上边：横向头像轨道
- 下边：横向头像轨道
- 左边：纵向头像轨道
- 右边：纵向头像轨道

头像卡只显示：

- 卡通头像
- 学生名字

不显示：

- 成绩
- 排名
- 完成度
- 评价标签
- 红黄绿风险标识

头像数量较多时：

- 每侧显示部分头像。
- 轨道可缓慢自动轮播。
- 老师可配置是否显示全名、昵称或仅头像。

### 2.4 底部插件栏

底部展示今日可用插件。

第一版建议保留 6 个：

1. AI 问答
2. 课文跟读
3. 听写播报
4. 课堂投票
5. 今日鼓励
6. 小组协作

插件栏在待机状态下可以低调展示，学生完成头像拖入后再变成可点击的主操作卡。

## 3. 四状态交互设计

### 3.1 状态 A：待机展示

目的：

- 给家长和学生看到系统正在运行。
- 展示整体学习过程，而不是个人差异。

推荐模块：

- 今日学习主题
- 今日任务概览
- AI 助教工作流
- 老师复核状态
- 共性学习观察
- 学生头像轨道
- 今日可用互动插件

示例文案：

> 今日学习主题：三年级数学 · 乘除法应用题巩固  
> AI 助教已生成反馈，老师正在复核学习记录

### 3.2 状态 B：拖拽头像

触发：

- 学生长按自己的头像卡约 0.5 秒。

动效：

- 头像卡轻微放大。
- 卡片上浮，出现阴影。
- 原位置保留淡淡占位。
- 拖动路径出现柔和光线。
- 中心学习光环亮起。

磁吸规则：

- 头像进入中心光环一定范围后，光环扩大。
- 出现吸附线和波纹。
- 松手后完成身份确认。
- 未进入范围就松手，头像回弹到原位置。

提示文案：

> 将头像拖入学习光环

### 3.3 状态 C：身份确认

完成拖拽后进入身份确认。

展示：

- 当前学生头像
- 学生名字
- 本次互动提示
- 可选插件入口

示例文案：

> 李子越，已进入本次互动  
> 本次记录将同步到学习档案

注意：

这里不是完整登录，不进入个人主页，只是确认本次互动的参与者。

### 3.4 状态 D：插件选择

身份确认后展示可用插件卡。

插件卡设计：

- 图标
- 插件名称
- 一句用途说明
- 是否需要老师开启

示例：

| 插件 | 文案 |
| --- | --- |
| AI 问答 | 说出你的问题，AI 先引导思路 |
| 课文跟读 | 跟读今日课文，记录朗读表现 |
| 听写播报 | 老师开启后进行锁屏听写 |
| 课堂投票 | 匿名选择，展示整体结果 |
| 今日鼓励 | 领取一条温和鼓励 |
| 小组协作 | 进入老师发布的小组任务 |

## 4. 插件功能边界

### 4.1 AI 问答

适合：

- 学生临时提问
- 课堂思路引导
- 家长参观时演示 AI 能力

规则：

- AI 回答要按年级降低表达难度。
- 涉及具体题目时优先给思路，不直接代写完整答案。
- 问答记录进入学生学习日志，教师端可复核。

### 4.2 课文跟读

适合：

- 英语课文
- 语文课文片段
- 重点词句练习

规则：

- 平板显示跟读句子和重点词。
- 不展示个人评分。
- 可记录是否参与、重点词是否完成。

### 4.3 听写播报

适合：

- 英语单词
- 语文词语
- 成语或课文重点词

规则：

- 听写期间进入锁屏播报。
- 不显示答案。
- 可显示当前第几题和剩余节奏。
- 听写结束后由老师决定是否展示词表。

### 4.4 课堂投票

适合：

- 选择题讨论
- 学习偏好调查
- 知识点理解判断

展示：

- 匿名整体比例
- 不显示谁选了什么
- 不显示正确率排名

### 4.5 今日鼓励

适合：

- 低压力互动
- 家长参观时体现系统温度
- 学生完成互动后的正反馈

文案风格：

- 具体
- 温和
- 不夸张
- 不比较他人

示例：

> 今天你愿意主动提出问题，这是一件很好的事。

### 4.6 小组协作

平板端只做入口和现场展示，不承载完整小队挑战。

完整挑战放在学生端。

平板可展示：

- 老师发布的小组任务
- 小组协作目标
- 当前课堂是否开启
- 进入学生端继续完成

不展示长期小组排名。

## 5. 电视投屏联动

平板端与电视端可以共享部分展示数据。

### 5.1 可同步内容

- 今日学习主题
- 今日任务概览
- AI 工作流状态
- 互动插件动态
- 听写/跟读/投票状态
- 共性学习观察

### 5.2 不同步内容

- 当前正在拖拽的学生身份
- 单个学生互动详情
- 学生个人问答全文
- 个人错题和档案

### 5.3 投屏展示方式

电视端不负责操作，只做更大屏幕展示。

平板端发生互动时，电视端可以显示：

> 一名同学正在参与 AI 问答  
> 课堂投票已开启，正在收集匿名结果  
> 听写播报进行中，第 3 题

不显示：

> 李子越正在答题  
> 李子越回答错误  
> 李子越完成度 80%

## 6. 教师端配置

教师端需要提供一个“平板展示配置”页面。

配置项：

- 当前平板模式
- 是否显示头像轨道
- 是否允许学生拖拽头像
- 是否开启 AI 问答
- 是否开启课文跟读
- 是否开启听写播报
- 是否开启课堂投票
- 是否开启今日鼓励
- 是否开启小组协作
- 是否同步电视投屏
- 是否显示共性薄弱点
- 是否显示任务完成概览

模式预设：

| 模式 | 用途 |
| --- | --- |
| 家长参观模式 | 展示整体数据、AI 流程、头像墙和插件入口 |
| 常规待机模式 | 简洁显示今日主题和可用互动 |
| 课堂互动模式 | 头像拖拽和插件入口优先 |
| 听写锁屏模式 | 只显示听写节奏，不显示答案 |
| 投屏展示模式 | 平板可操作，电视只读展示 |

## 7. 数据记录

平板端互动需要写入学习日志，但记录粒度要克制。

建议记录：

- 学生 ID
- 设备 ID
- 插件类型
- 互动开始时间
- 互动结束时间
- 互动摘要
- 是否需要老师复核

不建议记录：

- 公共屏可见个人评价
- 公共屏可见详细分数
- 未经复核的敏感 AI 判断

## 8. 第一版开发建议

第一版先实现：

1. 平板首页布局
2. 四周头像轨道
3. 长按拖拽头像
4. 中心学习光环吸附
5. 身份确认
6. 插件选择页
7. 教师端插件开关配置

第二版再实现：

1. 电视端实时同步
2. AI 问答真实语音输入
3. 课文跟读语音记录
4. 听写播报节奏控制
5. 匿名课堂投票
6. 学生端小队挑战联动

## 9. 设计验收标准

平板端设计完成后需要满足：

- 家长一眼能看懂系统在记录和分析学习过程。
- 学生能自然理解“拖头像进入学习光环”。
- 老师能控制哪些内容展示、哪些插件开启。
- 公共屏不会放大学生之间的比较。
- 电视投屏展示的是整体过程，而不是个人差异。
- 整体视觉有 AI 科技感，但不压迫、不冰冷。
