# 归零重建原则

## 边界

- 新仓库从产品、数据、AI skills、页面和服务接入重新搭建。
- `D:\君航AI助教` 只作为参考资料目录，读取其中的教材、学生档案、日志和历史输出，用于理解真实业务。
- 不直接复用旧项目脚本、旧机器人逻辑、旧飞书自动化流程。
- 旧数据后续如需迁移，先写迁移说明和字段映射，再做导入工具。

## 停止旧自动化

目标是停止旧飞书 CLI、本地机器人、localtunnel、旧 Node 服务等遗留运行项。执行原则：

1. 先列出进程命令行。
2. 只停止明确属于旧项目的进程。
3. 不停止 Codex、编辑器、系统服务或无法确认归属的 Node 进程。
4. 停止记录写入 `docs/ops-log.md`。

当前状态：进程命令行读取需要更高权限，尚未获得可用授权，因此暂不强制停止。

## 教材与参考来源

- 作业帮、小猿辅导、智慧中小学等只能作为题型、讲解方式、知识组织方式的参考。
- 不抓取、不复制、不内置未经授权的商业题库或版权内容。
- 已有电子教材库可作为本地教材索引参考；是否还需要补充，等完成教材清单、年级科目覆盖和版权边界检查后再判断。
