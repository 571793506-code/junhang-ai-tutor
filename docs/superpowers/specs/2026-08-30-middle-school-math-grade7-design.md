# 七年级人教版数学第一阶段设计

## 目标

为君航 AI 助教增加一个可实际使用的初中数学纵向闭环，第一阶段只覆盖七年级人教版数学，优先支持练习、小测和外部材料批改。

## 范围

- 支持“七年级”“初一”“7 年级”等输入的统一规范化。
- 支持七年级上册、下册真实教材资产和教师确认的章节上下文。
- 七年级数学练习、小测使用独立蓝图、知识主题和兜底题目。
- 外部练习册/试卷图片批改仍然是草稿，识别不清、步骤缺失、几何证明和图像题必须进入教师复核。
- Web 和小程序只采集年级、教材、章节和任务类型，核心判断留在服务层。

## 不在本阶段

- 八年级、九年级和中考综合题。
- 自动正式归档、自动发布和跳过教师确认。
- 重写现有 PDF 排版主流程。
- 通过固定调用 Sol 解决教材证据缺失或 OCR 不清的问题。

## 架构

### 共享年级契约

新增 `packages/core/src/grade-level.js`，提供规范化、显示标签和学段判断。规范化结果至少包含 `level=7`、`stage=middle`、`label=七年级`。未知年级返回 `null`，服务层对需要教材或生成的未知年级返回可识别的 422 错误，不再回退到六年级。

### 教材和上下文

教材请求必须匹配真实 `TextbookAsset` 的科目、年级、版本、册次和贵州遵义基准。章节仍通过资产 metadata/chapters 保存；已审核资料通过 `contentContext` 注入。小学资料不能匹配七年级请求。

### 生成

七年级数学使用独立的 `middleMath` 规则。第一阶段覆盖有理数、整式、一元一次方程、几何图形与数据基础等七年级主题。题型可以复用填空、选择、计算、解答，但每题必须保留答案、步骤、知识点、易错点和适度作答区；生成结果继续是教师复核草稿。

### 批改

外部材料先分离印刷题干与学生作答，再进行公式规范化和逐题判断。负号、分数、根式、上下标、方程步骤和几何证明不能只比较最终文本；低置信、步骤不全或题干/图形缺失时不出最终分、不归档。

### 多端

Web 和小程序共享同一组年级显示值和 API 字段。端侧不拼提示词、不计算学段、不决定教材匹配或批改置信度。

## 验收标准

1. `七年级`、`初一`、`7年级` 得到同一规范化结果，`六年级` 不会被识别为初中。
2. 七年级数学生成蓝图不再使用小学数学知识点和小学提示词。
3. 没有真实七年级教材资产或已审核上下文时，教材绑定请求在模型调用前失败关闭。
4. 外部数学批改对过程题、几何证明和 OCR 低置信项明确标记教师复核。
5. Web、小程序可选择七年级，但业务规则仍由服务层执行。
