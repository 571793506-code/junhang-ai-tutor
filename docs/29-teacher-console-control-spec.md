# 教师端控制台详细设计

## 1. 页面定位

教师端是整个系统的控制中心，但不是第一阶段重点展示对象。

设计目标：

- 老师能够快速完成日常操作。
- 老师能够控制平板端和电视端展示范围。
- AI 生成的内容必须经过老师复核。
- 学生端任务和小队挑战能够由老师灵活发布。
- 界面保持清晰、务实，不增加老师负担。

一句话定位：

> 教师端负责发布、控制、复核和归档。

## 2. 首页工作台

首页只放老师最需要关注的状态：

- 今日任务
- 待复核批改
- 待发布档案
- 平板设备状态
- 电视投屏状态
- 当前互动插件
- 小队挑战状态

推荐快捷操作：

1. 发布今日任务
2. 开启平板互动
3. 开启听写播报
4. 发起课堂投票
5. 新建小队挑战
6. 查看待复核记录

## 3. 学生与权限

保留现有能力：

- 学生登记
- 学生列表
- 学生专属码
- 登录权限开关
- 负责老师绑定
- 退课后保留档案

新增：

- 平板头像显示设置
- 昵称/全名/仅头像模式
- 是否允许公共平板互动
- 是否允许加入小队挑战

## 4. 今日任务发布

教师发布任务时可选择：

- 单个学生
- 多个学生
- 班级
- 年级
- 小队

任务字段：

- 科目
- 标题
- 内容
- 预计用时
- 截止时间
- 是否允许家长查看
- 是否进入错题复练
- 是否需要拍照提交
- 是否同步到平板提醒

AI 可辅助：

- 根据近期错题生成任务草稿
- 根据年级和知识点调整难度
- 根据预计用时控制任务量

最终由老师确认发布。

## 5. 练习、小测和试卷

保留现有能力：

- 生成练习
- 生成小测
- 生成试卷
- 按学生/年级选择范围
- 设置科目和难度
- A4 排版
- 导出题目和解析 PDF

增强：

- 从近期共性错因生成班级练习
- 从单个学生错题生成个性化复练
- 生成后预览
- 教师修改后导出

## 6. 拍照批改与复核

### 6.1 流程

> 拍照上传 -> OCR 识别 -> AI 初步批改 -> 教师复核 -> 写入错题和档案 -> 学生端反馈

### 6.2 教师端需要看到

- 上传图片
- OCR 识别文本
- 逐题结果
- 错误位置
- 错因建议
- 推荐复练
- 是否需要人工补充

### 6.3 控制原则

- AI 初步结果默认不直接发布。
- 老师可以修改措辞和知识点归类。
- 老师确认后才同步给学生端和家长视角。

## 7. 平板互动控制

教师端需要独立页面：`平板互动控制`。

### 7.1 设备选择

- 选择年级平板
- 查看在线状态
- 查看当前模式
- 解锁/锁定
- 开启/关闭头像拖拽
- 开启/关闭电视同步

### 7.2 模式预设

| 模式 | 默认开启内容 |
| --- | --- |
| 家长参观模式 | 整体数据、头像轨道、AI 工作流、插件预览 |
| 常规待机模式 | 今日主题、任务概览、头像轨道 |
| 课堂互动模式 | 拖拽解锁、插件选择 |
| 听写锁屏模式 | 听写节奏、题号、播报控制 |
| 课文跟读模式 | 课文内容、重点词、跟读控制 |
| 投屏展示模式 | 平板可操作、电视匿名展示 |

### 7.3 插件开关

老师可以按年级平板开启：

- AI 问答
- 课文跟读
- 听写播报
- 课堂投票
- 今日鼓励
- 小组协作

每个插件需要显示：

- 当前状态
- 是否需要老师确认
- 是否同步电视端
- 是否写入学生档案

## 8. 电视投屏配置

教师端需要独立页面：`电视展示配置`。

可配置：

- 开启/关闭电视投屏
- 选择年级/班级
- 家长参观模式
- 纯品牌展示模式
- 是否显示头像墙
- 是否显示昵称
- 是否显示整体人数
- 是否显示任务完成概览
- 是否显示共性学习观察
- 是否显示互动插件动态
- 是否显示阶段成果

教师端需要预览电视端画面。

## 9. 课堂投票

教师可快速创建：

- 选择题投票
- A/B/C 判断
- 学习偏好调查
- 课堂理解检查

字段：

- 问题
- 选项
- 开放时间
- 是否匿名
- 是否投屏展示结果
- 是否公布答案

默认：

- 匿名
- 不记录公开个人选择
- 电视端只展示整体比例

## 10. 小队挑战配置

教师端可以创建不定期家庭学习活动。

字段：

- 挑战主题
- 挑战类型
- 参与年级/班级
- 小队分组方式
- 开始时间
- 结束时间
- 知识地图节点
- 每个节点任务
- 协作徽章
- 是否显示电视端预告

小队分组方式：

- 老师手动分组
- 系统随机分组
- 按年级固定小队

不提供：

- 长期公开排名
- 个人贡献倒序榜
- 低完成度学生公开提醒

## 11. 学生档案发布

保留现有“AI 草稿 -> 老师复核 -> 发布”的逻辑。

档案内容：

- 近期学习概览
- 表现较好的地方
- 待巩固内容
- 近期错题与订正重点
- 下一步建议
- 周/月/期中/期末反馈

老师可以：

- 修改文字
- 删除敏感表达
- 补充人工建议
- 选择发布到学生端
- 选择是否允许家长查看

## 12. 第一版页面清单

第一版：

1. 教师工作台
2. 学生与权限
3. 今日任务发布
4. 练习/小测/试卷生成
5. 拍照批改
6. 批改复核
7. 学生档案发布
8. 平板互动控制
9. 电视展示配置
10. 小队挑战配置

第二版：

1. 教材与知识点管理
2. 批量任务发布
3. 投票模板
4. 挑战模板
5. 阶段报告批量复核
6. 家长沟通素材生成

## 13. 验收标准

教师端设计完成后应满足：

- 老师能在较少步骤内发布任务。
- AI 结果不会绕过老师直接作为最终结论。
- 老师能一键切换平板和电视展示模式。
- 老师能明确控制互动插件的开启范围。
- 老师能发起学生端小队挑战。
- 公共屏展示范围可控，不泄露学生隐私。
