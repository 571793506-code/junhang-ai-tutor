# 路线图

## Phase 0：归零与基础约定

- 明确旧目录只读参考。
- 停止旧飞书/机器人遗留进程。
- 重新准备飞书、DeepSeek、MiniMax、GitHub 接入。
- 建立数据模型、AI skills、页面信息架构。

## Phase 1：Web 模拟端 MVP

- 学生管理。
- 今日任务。
- AI 答疑。
- 英语词汇助手。
- 背书听写文本版。
- 作业/试卷生成。
- 批改结果录入。
- 错题本。
- 日/周报告生成。

## Phase 2：小程序定稿

- 根据 Web 模拟端确定小程序页面。
- 接入登录和学生/家长/老师身份。
- 接入数据库与真实模型服务。
- 接入飞书通知。
- 完成核心流程测试。

## Phase 3：智能批改与教材库

- 图片上传与 OCR。
- 试卷结构化。
- 教材索引。
- 知识点树。
- 题目生成质量评估。

## Phase 4：AI 教学实验室

- PPT 课件生成。
- 英语虚拟人物对话。
- 语文作文场景。
- 数学几何 3D 模型。
- 投影仪课堂模式。

## Phase 5：运营与质量

- 模型输出审核。
- 家长报告质量评估。
- 成本监控。
- 数据备份。
- 隐私与权限加固。
