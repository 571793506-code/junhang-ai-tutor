# 小程序演示视频脚本

## 通用录制规则

- 全部使用测试学生和测试教师。
- 不展示真实姓名、真实电话、真实资料库和内部配置。
- 教师端只展示非敏感信任链路，不展示核心后台。
- 视频结尾统一指向：期末后 3 天 AI 学习诊断体验预约。
- 统一表达：AI 辅助分析，老师复核把关。

## 视频 1：总览演示

时长：60-90 秒。

标题：

> 君航 AI 助教：让学习过程看得见

### 分镜

1. 角色入口
   - 画面：学生端、教师端、课堂平板端入口。
   - 字幕：三端协同，记录学习过程。
   - 旁白：君航 AI 助教不是让孩子自己搜答案，而是一套学习过程记录与反馈系统。

2. 学生端首页
   - 画面：今日任务、学习观察、功能模块。
   - 字幕：任务由老师发布。
   - 旁白：学生登录后，可以看到老师发布的今日任务和自己的学习观察。

3. 拍照提交
   - 画面：选择作业批改/小测批改/听写批改，上传图片。
   - 字幕：作业、小测、听写都可提交。
   - 旁白：孩子完成的作业、小测和听写，可以拍照提交，进入后续复核流程。

4. AI 问答与词汇
   - 画面：AI 问答、英语词汇助手。
   - 字幕：先给思路，再由老师把关。
   - 旁白：不会的问题可以先得到思路引导，英语词汇可以查看词性、变化和易错点。

5. 教师复核
   - 画面：测试教师端的批改复核列表，不展示敏感配置。
   - 字幕：AI 初步分析，老师复核发布。
   - 旁白：AI 的分析不会直接作为最终结论，老师确认后才进入学生档案。

6. 学生档案
   - 画面：知识掌握、错题记录、阶段反馈。
   - 字幕：家长看见真实学习过程。
   - 旁白：家长能看到孩子做了什么、错在哪里、下一步怎么练。

7. 平板与大屏
   - 画面：课堂平板头像确认、电视动态屏。
   - 字幕：公共屏只展示整体，不公开比较孩子。
   - 旁白：平板用于课堂互动，电视展示匿名流程，不显示排名、分数和个人错题。

### 结尾

字幕：

> 期末后 3 天 AI 学习诊断体验开放预约

旁白：

> 新四、新五、新六学生可预约体验，名额有限。

## 视频 2：学生端演示

时长：60 秒。

### 分镜

1. 学生登录
   - 画面：学生姓名、家长电话、学生专属码。
   - 旁白：学生使用姓名、家长电话和专属码登录。

2. 首页
   - 画面：今日任务、待处理练习、学习观察。
   - 旁白：首页可以看到今天要完成什么，以及近期需要关注的学习方向。

3. 今日任务
   - 画面：老师发布的任务列表。
   - 旁白：任务由老师发布，学生端负责查看和完成。

4. AI 问答
   - 画面：输入问题和 AI 回答。
   - 旁白：AI 问答优先做思路引导，不是直接替孩子写答案。

5. 英语词汇
   - 画面：查单词、词性、中文说明、词形变化。
   - 旁白：英语词汇助手帮助孩子记住词性、变化和易错点。

6. 拍照提交
   - 画面：选择提交类型，上传图片。
   - 旁白：作业、小测、试卷、听写都可以提交，等待老师复核。

7. 学生档案
   - 画面：知识掌握、错题记录、阶段反馈。
   - 旁白：老师确认后的反馈，会沉淀到学生档案。

## 视频 3：课堂端与大屏演示

时长：45-60 秒。

### 分镜

1. 平板公共课堂屏
   - 画面：课堂平板端、学习光环、测试学生头像。
   - 旁白：课堂平板是公共设备，只用于本次课堂互动确认。

2. 头像确认
   - 画面：点击测试学生头像，进入本次互动。
   - 旁白：学生确认身份后，可以参与本次课堂互动。

3. 插件入口
   - 画面：AI 问答、听写播报、课文跟读。
   - 旁白：平板端可用于课堂问答、听写播报和课文跟读。

4. 电视动态屏
   - 画面：学习运行概览、AI 学习中枢、匿名动态。
   - 旁白：电视大屏只展示整体流程，不公开学生排名、分数和个人错题。

## 视频 4：教师复核信任链路演示

时长：45-60 秒。

### 分镜

1. 教师工作台概览
   - 画面：测试教师端服务状态、功能入口。
   - 旁白：教师端负责发布、复核和归档。

2. 今日任务生成
   - 画面：选择测试学生和科目，生成任务草稿。
   - 旁白：老师决定任务方向，AI 辅助起草。

3. 批改复核
   - 画面：测试学生提交记录进入复核列表。
   - 旁白：作业、小测和听写提交后，会进入老师复核。

4. 发布反馈
   - 画面：学生档案反馈。
   - 旁白：老师确认后，反馈才进入学生档案和家长可见记录。

### 禁止录入画面

- 资料上下文内部来源。
- 生成提示词。
- 模型供应商。
- API 配置。
- 真实学生和真实家长信息。
