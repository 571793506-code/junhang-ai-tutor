# 君航 AI 助教小程序端

当前目录是原生微信小程序第一版骨架，目标是让学生端、教师端、平板课堂端先共享 `apps/api` 的 HTTP 接口。

## 当前阶段

- 已建立原生小程序工程配置。
- 已接入学生登录、教师登录、启动包、AI 问答、任务生成、拍照上传批改等接口。
- 学生端只显示学习相关内容，不展示模型和导入计划。
- 教师端显示终端控制、学生权限、任务生成、批改上传和服务状态。
- 平板端先提供课堂任务、学生头像解锁、课堂问答入口。

## 本地运行

1. 先启动 API：

```bash
npm run dev:api
```

2. 使用微信开发者工具打开 `apps/miniprogram`。
3. 开发阶段请在微信开发者工具中勾选“不校验合法域名、web-view、TLS 版本以及 HTTPS 证书”。
4. 默认接口地址是：

```text
http://127.0.0.1:8787
```

真机调试时需要把 `app.js` 里的 `apiBaseUrl` 改成电脑局域网 IP，例如 `http://192.168.1.20:8787`，并确保手机和平板与电脑在同一网络。
